# To-Do Python

A small command-line to-do list I wrote in Python. You add a task with a deadline,
and it saves everything in a text file, so your list is still there next time.

## what it does

~ add a task with a description and a deadline (each one gets an ID)
~ show all your tasks
~ mark a task as done by its ID
~ keeps tasks saved in a text file between runs

## how to run it

You need Python 3.

    git clone https://github.com/ineek808/to-do-python.git
    cd to-do-python
    python main.py

Pick an option from the menu and follow the prompts.
