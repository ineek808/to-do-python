
# Project Title

A brief description of what this project does and who it's for

A simple command-line to-do list app in Python that stores tasks (with ID, description, deadline) in a text file, letting users add, view, and complete tasks via a menu.

## Features

- Add tasks with a description, deadline, and unique ID
- View all saved tasks in a readable format
- Complete/delete tasks by ID
- Persistent storage using a text file
